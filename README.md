# Белорусская локализация S.T.A.L.K.E.R.: Call of Pripyat

1. Распакуйте архив в папку игры, чтобы `gamedata` и `fsgame-bel.ltx` оказались рядом с папкой `bin_original`.
2. Создайте ярлык для `bin_original\xrEngine.exe`. В поле «Объект» добавьте после пути к файлу аргумент `-fsltx fsgame-bel.ltx`, а в поле «Рабочая папка» укажите папку игры.
3. Запустите игру через этот ярлык.

Локализация использует оригинальные файлы игры и существующие сохранения. Пакет содержит переведённые текстовые ресурсы; изображения и видео не изменены.
