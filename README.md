# Белорусская локализация S.T.A.L.K.E.R.: Call of Pripyat

1. Распакуйте архив в папку игры. Папки `gamedata` и `bin_original` должны находиться рядом, а `fsgame-bel.ltx` должен лежать в корне игры.
2. Создайте ярлык. В поле «Объект» укажите `"<папка игры>\bin_original\xrEngine.exe" -fsltx fsgame-bel.ltx`, а в поле «Рабочая папка» — `<папка игры>`.
3. Запустите игру через этот ярлык.

Локализация использует оригинальные файлы игры и существующие сохранения. Пакет содержит текстовые ресурсы; изображения и видео не изменяются.
