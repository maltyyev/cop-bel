# Белорусская локализация S.T.A.L.K.E.R.: Call of Pripyat

Поддерживается оригинальная игра версии 1.6.02 с папкой `bin_original` в корне. Если в игре уже есть папка `gamedata` или установлены моды, заранее сохраните её копию: файлы локализации могут совпасть с файлами модов.

1. Распакуйте содержимое архива в корень игры, рядом с `bin_original`. Если скачали ZIP исходного кода с GitHub и внутри есть папка `cop-bel-main`, распакуйте в корень игры содержимое этой папки. В корне должны появиться `gamedata` и `fsgame-bel.ltx`.
2. Создайте ярлык. В поле «Объект» укажите `"<папка игры>\bin_original\xrEngine.exe" -fsltx fsgame-bel.ltx`, а в поле «Рабочая папка» — `<папка игры>`.
3. Запустите игру через этот ярлык.

Локализация использует оригинальные файлы игры и существующие сохранения. Пакет содержит текстовые ресурсы; изображения и видео не меняются.
