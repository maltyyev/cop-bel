# Беларуская лакалізацыя S.T.A.L.K.E.R.: Call of Pripyat

1. Распакуйце архіў у папку гульні, каб `gamedata` і `fsgame-bel.ltx` апынуліся побач з папкай `bin_original`.
2. Стварыце ярлык для `bin_original\xrEngine.exe`. У полі «Аб'ект» дадайце пасля шляху да файла аргумент `-fsltx fsgame-bel.ltx`, а ў полі «Рабочая папка» пакажыце папку гульні.
3. Запусціце гульню праз гэты ярлык.

Лакалізацыя выкарыстоўвае арыгінальныя файлы гульні і існуючыя захаванні. Пакет змяшчае перакладзеныя тэкставыя рэсурсы; выявы і відэа не змяняюцца.
