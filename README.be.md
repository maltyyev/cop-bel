# Беларуская лакалізацыя S.T.A.L.K.E.R.: Call of Pripyat

Падтрымліваецца арыгінальная гульня версіі 1.6.02 з папкай `bin_original` у корані. Калі ў гульні ўжо ёсць папка `gamedata` або ўсталяваныя моды, загадзя зрабіце яе копію: файлы лакалізацыі могуць супасці з файламі модаў.

1. Распакуйце змесціва архіва ў корань гульні, побач з `bin_original`. Калі спампавалі ZIP зыходнага кода з GitHub і ўнутры ёсць папка `cop-bel-main`, распакуйце ў корань гульні змесціва гэтай папкі. У корані павінны з'явіцца `gamedata` і `fsgame-bel.ltx`.
2. Стварыце ярлык. У полі «Аб'ект» укажыце `"<папка гульні>\bin_original\xrEngine.exe" -fsltx fsgame-bel.ltx`, а ў полі «Рабочая папка» — `<папка гульні>`.
3. Запусціце гульню праз гэты ярлык.

Лакалізацыя выкарыстоўвае арыгінальныя файлы гульні і існуючыя захаванні. Пакет змяшчае тэкставыя рэсурсы, 26 беларускіх галасавых рэплік Глушца, 40 беларускіх галасавых рэплік Дзегцярова і беларускую гукавую дарожку ўступнага роліка; арыгінальныя відэакадры застаюцца без зменаў.
